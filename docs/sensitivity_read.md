# Sensitivity read: a request for 2-3 readers

Thanks for reading this. It should take about 15 minutes.

## What this is

**Counterfactual: The Jackson Trajectory** is a portfolio project. It's a scenario model that changes one input in Michael Jackson's documented life, his father's parenting style, and shows how the outcomes shift across 10,000 simulated runs. Every result is a range under stated assumptions, not a prediction. The criminal allegations are out of scope.

Before anything goes public, I'm asking a few people, including at least one who knows the culture and the fanbase, to read it with fresh eyes.

## The one question

> **Does any sentence claim more than the model can say, or land wrong?**

"Land wrong" covers anything that reads as disrespectful, sensational, careless about his death, unfair to his father or siblings, or tone-deaf. Plain reactions are the most useful. You don't need to judge the math.

## What to read

1. **The README** (about 4 minutes): https://github.com/rajisworking16/jackson-counterfactual/blob/main/README.md
2. **The dashboard**, if you have 10 more minutes. You can run it yourself:
   ```bash
   git clone https://github.com/rajisworking16/jackson-counterfactual.git
   cd jackson-counterfactual
   python3 -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   streamlit run app/streamlit_app.py
   ```
   It opens in your browser. Page 1 is the documented timeline, page 2 is the dials and results, page 3 is the assumptions and limitations. If you'd rather not run it, the screenshots at the end of the README show all three pages.
